# 平台参数定义彻底删除

> English: [English](../../../exec-plans/active/2026-10-20-parameter-definition-erasure.md)

状态：本地实现完成，PR CI 与合入验证由交付协调者负责。用户已于 2026-10-20 确认范围。

## 授权目标

平台超级管理员可永久删除共享参数定义及其在全部组织中的值、修订和关联记录，原始 DTS/JSON 文件保持原样。这为 ADR-0040/0041 的永久身份与历史保留政策增加受控删除例外；普通发布、参数写入和数据库角色限制保持不变。

## 不变量

- 只有全局 `platform-admin` 可预览和执行。预览与删除使用相同关联闭包；过期预览不能授权已经变化的删除范围。
- 删除目标定义、全部修订与发布头、绑定、值、历史，以及关联治理和旧模型记录。共享来源实例、文件、其他定义及其实际值保留。
- 关联的多参数请求撤除，不保留针对已变化内容的审批；幸存替换值只解除旧参数来源引用，不删除新参数的值。
- Catalog 发布包、嵌入来源文档和物化指纹同步重建。幸存定义和修订的身份、内容保持不变。旧 pin 失效；缓存和后续安装不得恢复已删除定义。
- 清理数据库和对象归档中的参数副本，保留嵌入的原始配置文件。对象删除失败可重试，不能报告删除已经完成。
- 保留删除标记和审计，只记身份、操作者、计数及前后摘要，不保留被删除的定义正文或值。

## 实现与验证

1. Catalog owner 生成并验证确定性的删除计划；受限 SQL 在既有 Catalog/发布锁下同事务应用计划和关联删除。
2. 平台专用预览/删除 API 协调事务、对象清理和审计。界面只需一次影响确认，完成后刷新当前目录。
3. 真实 PostgreSQL 验证非空删除、跨组织范围、其他参数和值保留、循环、回滚、过期/并发、角色、归档、发布包修复及禁止复活。
4. 前端定向测试与真实 API 浏览器验证平台权限、预览、错误和完成；执行静态检查、构建、契约/数据库文档及独立破坏性逻辑审查。

同一工作树中已完成的模块与导航修改继续保留。实现验证不执行生产删除或部署。

## 文档更新门禁

根据最终迁移重新生成契约和数据库文档，执行 `npm run contract:check`、`npm run docs:check`，保持中英文修正一致。实际验证结果与计划、尚未执行的验收分开记录。

## 归档配置与兼容范围

项目参数平面归档使用现有原始文件对象存储。历史加密迁移归档还需配置 `WISEEFF_CATALOG_ARCHIVE_ROOT` 和 `WISEEFF_CATALOG_ARCHIVE_KEY_HEX`（原始 32 字节密钥，以 64 位十六进制表示）。两者均无默认值，不得以新密钥替换原密钥。

删除前校验全部归档。项目平面 v2 归档保留原始文件对象与结构，移除参数专属行及结构化快照。原生迁移的 `legacy-row` 图和单身份 `legacy-source-row` 图在解密及校验后可删除。未知或混合的加密图（例如包含其他参数或原始文件）会在数据库删除前中止，须先迁移为可处理的归档格式。缺失密钥、归档损坏或对象仍有保留引用时，也不会误报已全部完成。
