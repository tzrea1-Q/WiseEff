# 配置参数编辑整改

> English: [Configuration value editor refinement](../../../exec-plans/active/2026-10-19-configuration-value-editor.md)

方向调整：用户要求完整 DTS 源码编辑和预览／编辑切换，替代方案见 [DTS 源码编辑实施方案](2026-10-19-dts-source-editor.md)。下文实施和验证仍作为旧类型编辑器的历史记录；本次方案更新尚未实施源码编辑替代。

状态：已在 `codex/frontend-ui-refinement` 本地实施，扩大回归范围的完整验收仍未完成。同工作树中已有且未提交的导航过滤改动已保留。使用本地 API 环境；本次实施请求不包含交付发布、部署或设备写入。

范围为用户已确认实施的详细方案：有限预览、共用本地草稿的宽编辑窗口、有序字符串列表与数组、明确的批量输入格式、未完成输入无损保留、固定定义修订的约束校验、真实的本地存储状态及待审核反馈。复用既有 AST、会话、对话框和 UI 控件，不新增依赖或数据库迁移。

## 实施顺序

1. 修复共用解析、完整字符校验、字符串转义、字节和精确整数边界；保留原格式和混合值，并检查其他解析调用者。
2. 实现紧凑类型编辑、侧栏六项预览、展开每页五十项、批量预览、有序增删移动及可访问的字段错误。
3. 在现有隔离草稿存储中保存未完成数值及其分组位置，兼容旧草稿；报告存储失败，保存回执不能清除后续新输入。
4. 接入固定定义元数据、宽编辑、错误、原值折叠和底部差异摘要；输入只更新计数，不自动展开底部面板。
5. 验证当前组合改动，更新现有中英文前端与用户指南；分别报告聚焦测试、选定回归、浏览器证据及未运行检查。

## 验收

覆盖 1/20/200 项列表和数组、2,000 项压力样本、空项/重复项/转义字符串、清空中间数值、未完成 token、32/64 位边界、分组、字节、重复或带参数引用、混合值及布尔删除。检查模式切换、参数切换、刷新、权限锁、过期基线、失败或部分保存，以及保存期间的新输入。真实 API 浏览器检查使用 1440×900 和一个紧凑 PC 窗口，检查外观、键盘焦点和错误反馈。

执行聚焦行为测试，运行 `test:impact` 并检查两个 fallback 标志，以及变更静态覆盖、构建和选定 UI/文档/契约检查。选定的必需检查仍需执行；聚焦通过不代表全量回归或 CI 验收。恢复与并发改动需要独立审视。

受影响的验收与操作编号为 `PROJ-CONFIG-EDIT-001`、`PROJ-CONFIG-DRAFT-001` 和 `PROJ-CONFIG-INSPECT-001`，归属 `e2e/acceptance/project-configuration-workbench.acceptance.spec.ts`。保留既有类型保存、恢复和检查器覆盖，将输入后自动展开的旧预期改为主动打开本轮更改。宽编辑、批量格式、未完成单元格恢复和保存竞争另有聚焦组件/会话测试及真实 API 浏览器观察。

## 本地验证

前端全量通过：531 个文件、5,301 项测试，无失败或跳过。Bridge 全量通过 21 个文件、142 项测试。构建、变更静态覆盖、UI 规范、文档和契约检查通过。独立恢复/并发审视发现的问题已修复并复核。

真实 API 浏览器在 1440×900 和 1280×800 验证了转义/空项/重复字符串、未确认文本刷新恢复、空的分组单元格、表格粘贴、2,000 项分页、精确 64 位溢出、字节、重复引用、混合值、布尔删除、撤销和键盘焦点。合成项目没有规范保存 Binding，因此这些观察不代表该项目已成功完成受审核保存。

导航与编辑器组合改动的两个影响选择 fallback 标志均为 true。扩大范围的后端、脚本和浏览器运行在发现失败后中断：Agent 用例要求不同的 PostgreSQL lane；并发共用实例期间数据库租约用例超时；真实三存储用例失败；`/dts-reload` 的 Bridge 位置断言失败。其余全量浏览器选择及选定的验收 spec 未完成。这些尝试不能计为全量回归通过，日志保留在被忽略的 `test-results/local-dev/` 下。合入前仍需完成后端/脚本/浏览器全量检查和当前提交的 CI。Linux 视觉基线、部署及真实硬件验收均未验证。

数据库租约文件已在独立 PostgreSQL 实例中单独重跑，32 项全部通过。操作证据辅助文件在 API 模式下 37 项全部通过；该文件的 API 专用预期在选择器给出的 mock 模式脚本命令下失败。两次聚焦复核均不能替代尚未完成的全量运行。
