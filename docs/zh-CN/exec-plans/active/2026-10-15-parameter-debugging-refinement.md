# 参数调试整改

> English: [Parameter debugging refinement](../../../exec-plans/active/2026-10-15-parameter-debugging-refinement.md)

范围：`/dts-reload`、参数详情、本轮变更、预检/结果/历史、共用 Bridge 入口和组织重载配置。基线 `24b5bc2f0`，分支 `codex/frontend-ui-20261015`。用户已授权修复本地界面筛查的全部发现；本任务不包含生产部署或真实设备写入。

## 验收清单

- [x] 项目切换、离页及刷新保护编辑器和本轮变更。
- [x] 候选、预检、部署、恢复、历史和残留异步结果与当前上下文隔离；提供重试、加载和未知状态。
- [x] 操作后刷新历史与上次重载信息而不清空当前编辑；统一运行链接。
- [x] 区分成功、提示与错误，保持下一步操作易于找到。
- [x] 合并项目/协议控制区；统一主要滚动区，提供清晰区段导航。
- [x] 1440×900 和 1280×800 下操作列完整可见，保存栏不遮挡表单。
- [x] 统一参数编辑入口及即时校验，优先展示含义和约束，明确语法示例语境。
- [x] 不可调试参数仍可只读查看，主表展示本轮值和变更状态。
- [x] 展示筛选范围，区分空状态并提供统一清除。
- [x] 运行结果优先展示参数差异与下一步，源码、哈希和详细步骤渐进展开。
- [x] 统一中文日期和状态，技术标识作为辅助信息保留。
- [x] 组织配置分组、展示最终设置和修改信息，关联标签及字段提示。
- [x] 配置加载失败时禁用编辑并提供重试，服务端拒绝过期并发保存。
- [ ] 完成影响范围内的测试、静态检查、构建、API 模式桌面走查及并发改动独立审查。
