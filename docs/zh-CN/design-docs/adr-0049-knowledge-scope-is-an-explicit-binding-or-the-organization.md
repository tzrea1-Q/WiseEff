# ADR-0049：知识范围是显式绑定或整个组织

> English: [English](../../adr/0049-knowledge-scope-is-an-explicit-binding-or-the-organization.md)

日期：2026-10-21

## 状态

已接受。于 2026-10-21 用户自管知识设计会话中敲定，由[用户自管知识计划](../exec-plans/completed/2026-10-21-knowledge-user-curation.md)交付。

## 决策

每个知识消费方——小泽、分析技能、参数定义和调试界面——都在一个**知识范围**内检索已发布条目。范围只能是两者之一：绑定在消费方自身对象（分析技能、参数定义）上的显式条目身份集合，或整个组织。它永远不是标签查询、相似度规则或任何其他动态选择。范围只收窄检索，永远不会扩大到调用者所在组织已发布条目之外。

这样选择是因为：已发布的技能版本会冻结其可用条目，每次运行会固定实际检索到的知识修订。按标签定义的范围会让之后任何一次上传或改标签悄悄改变已发布技能的检索内容，破坏这份来源记录。批量导入会把文件夹名变成标签，因此标签是上传者控制的标记，而不是经过策划的范围。

## 备选方案

- **按标签绑定**（"该技能使用所有带「充电」标签的条目"）。因上述来源记录原因拒绝。选择器仍可提供"添加所有带 X 标签的条目"作为编辑快捷方式，在编辑消费方时展开为条目身份。
- **参数定义的自动相似度绑定。** 拒绝：定义只展示被显式引用的知识，定义页不会暗示没人确认过的关联。
- **按上下文收窄小泽检索**（只搜索当前页面绑定的条目）。拒绝：小泽始终在整个组织内检索，相关上传不会因对话从哪里开始而被隐藏。
- **新增调试节点与知识的绑定。** 拒绝：调试界面从其已绑定的参数定义推导范围。

## 影响

- 每个消费方以自己的权限规则拥有其绑定。技能绑定属于技能。定义引用属于条目，因为它描述条目讲的是什么；从任一侧添加都需要能治理该条目。
- 归档的条目退出所有范围，绑定行保留并显示为已归档。被彻底删除的条目留下悬空身份，消费方显示为已删除；已完成运行的来源记录永不改写。
- 显式集合为空的消费方，仅在该回退本就是其既定行为时回退到组织范围（分析技能，报告为组织通用范围）；定义和调试界面则不显示任何内容。
