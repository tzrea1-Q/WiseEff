# ADR-0050：工作流发布是全平台统一的界面开放策略

> English: [Workflow publication is platform-wide UI availability](../../adr/0050-workflow-publication-is-platform-wide-ui-availability.md)

## 状态

已接受。用户于 2026-10-23 完成始于 2026-10-22 的设计访谈，确认完整设计并授权实现。本决策取代 ADR-0036 的静态发现入口策略；验证、部署状态与设计接受分开判断。

## 已确认决策

仅平台超级管理员可以配置发布状态，配置对所有组织统一生效，控制单位为整项工作流。未发布工作流对普通用户隐藏界面入口并拦截直接页面访问；组织管理员和平台超级管理员仍可看到，但继续受原有数据和操作权限约束。发布配置不授予权限，也不禁用现有 API 或小泽能力。

这项需求调整了 [ADR-0036](../../adr/0036-workflow-discovery-uses-a-visible-workflow-allowlist.md) 的边界：本次产品控制明确包含运行时管理和直接页面访问，而旧方案只隐藏发现入口。将发布状态与能力授权分开，可以让管理员体验实验性界面，同时保留现有集成和组织隔离。按组织配置、逐页面开关以及禁用底层能力均已在本轮范围决策中排除。

## 已确认的运行行为

- 参数管理、设备调试、日志分析、知识库初始保持已发布，由超级管理员主动关闭。未来新增工作流默认未发布，必须显式发布；新增项缺少配置时不能默认为开放。
- 保存后的配置在用户下一次完整刷新或页面跳转时生效。已经打开的页面不被轮询清退或强制卸载；离开编辑页面前仍执行既有未保存确认，页面内查询、筛选或标签切换不视为进入新页面。新的页面跳转必须使用当前发布状态；获取失败时不能借用旧状态悄悄放行目标页面。
- 知识库未发布时，其他已发布工作流保留已有权限允许的只读知识参考。普通用户看不到跳转到知识库页面、创建知识条目及沉淀到知识库的入口。小泽和 API 的能力权限不变，包括知识检索。这是界面发布策略，不是内容保密策略。
- 首次加载发布配置失败时，普通用户可使用首页和重试入口，但在发布状态明确前不能进入工作流。管理员继续按已有权限使用页面。初次加载期间不能先闪现全部工作流为可用。

## 管理界面

为平台超级管理员增加独立的**工作流发布**入口，路径为 `/workflow-publication`，与组织管理、审计中心等工具入口并列，位于四项受控工作流之外。页面列出四项工作流、已发布或未发布状态及带明确标签的开关，提供保存、放弃修改和最后保存人、保存时间。切换开关先修改本地草稿，仅在显式保存成功后对全平台应用。沿用已有设置表单的未保存状态、离页确认和校验方式。

组织管理员仍能访问所有工作流界面，但不显示该管理入口，也不能进入该管理页。管理员可见的未发布工作流可以标注为管理员预览。首页、登录、恢复入口及管理工具不受发布开关控制，即使四项全部关闭也保持可达。首页显示尚无已发布工作流的空状态，不能留下失效链接或空标签页选择。直接网址被拦截时显示“暂未开放”及返回首页入口，不加载被拦截的工作流页面。

## 实现边界

- 复用现有工作流目录和页面、分组映射。侧栏、首页卡片、标签页、头尾导航及文案、路由别名与子路由、业务内跳转入口共同使用同一份面向当前用户的发布状态。日志技能详情的特殊权限规则仍须与发布状态共同判断。
- API 模式的首页发现入口已经要求登录，因此发布状态读取也要求登录。普通客户端只取得所需发布状态，管理元数据仅平台超级管理员可读。小泽仍可返回权限允许的数据和引用；引用若指向未发布工作流页面，打开时仍经过统一的前端路由拦截。
- 持久化一份平台级发布配置，独立于组织配置。服务端校验工作流标识和布尔状态；只有有效的平台超级管理员且具备非项目限定的平台角色绑定才可修改。隐藏管理入口不能替代服务端写入鉴权。
- 保存时使用读取到的配置版本检测并发修改，并在同一事务记录可信操作者及变更前后状态的平台审计事件。冲突或保存失败保留本地草稿，不提示成功。初始化可重复执行，但不能重新开放已被管理员关闭的工作流。
- 首次读取和跳转时刷新配置均须区分“未发布”与“配置暂不可用”，保留重试入口。本次不引入实时撤回、新的授权体系、组织套餐、内容删除、API 关闭或后台任务取消。

## 验收场景

1. 关闭日志分析或知识库后，配置可跨服务重启保留，两个不同组织的普通用户在下次刷新或跳转时均受影响；原有业务权限和组织隔离继续生效。
2. 侧栏、首页发现入口、业务内创建与跳转入口保持一致；直接链接、别名、子页面及浏览器导航均不能加载未发布工作流。已有权限允许的只读知识参考仍可使用，但不提供进入隐藏页面的链接。
3. 两类管理员均能访问未发布工作流；只有平台超级管理员能进入和修改发布管理页。服务端拒绝未授权配置写入和伪造项目级角色授权。
4. 配置变化不清退正在编辑的用户，离开时仍执行既有未保存确认。首次加载或跳转刷新配置失败提供重试，不放行普通用户进入状态未确认的目标页面；管理员仍可恢复配置。
5. 四项工作流全部关闭时，首页、登录和管理工具仍可用。当前四项初始已发布；未知或新增工作流必须显式配置后才能开放。
6. 保存失败、旧版本冲突和审计失败不能部分应用配置，也不能丢弃本地草稿。成功保存记录真实变更及可信操作者。

用户已确认完整设计并授权实现。本记录陈述接受的产品边界，本地测试与浏览器检查不构成部署或生产验收。
