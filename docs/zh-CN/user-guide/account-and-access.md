# 账号与访问

> English: [English](../../user-guide/account-and-access.md)

## 谁可以操作

只有部署方开启本地自助注册时，新用户才能注册。访客、硬件开发和软件开发注册后可直接使用；硬件MDE、软件MDE 申请需经管理员审批。已登录的本地账号用户可以修改自己的密码。具有 `users:manage` 权限的管理员（`admin`）和平台超级管理员（`platform-admin`）可以在自己的归属组织审批申请、重置本地密码。两种管理员角色均不能通过自助注册获得。

## 注册本地账号

1. 打开部署地址的受保护工作流，例如 `/parameter-home`，或从首页进入工作流。API 模式下，未登录用户会看到「登录雷泽」，选择「注册」。如果没有「注册」页签，请联系管理员获取账号，不要尝试绕过注册限制。
2. 填写姓名、用户名、角色、密码和确认密码。用户名为 3–64 个字符，可使用字母、数字、点、下划线或连字符；密码至少八个字符。以表单校验提示为准。
3. 选择访客（`guest`）、硬件开发（`hardware-user`）、软件开发（`software-user`）、硬件MDE（`hardware-committer`）或软件MDE（`software-committer`）。角色选择框使用英文角色名，下方提示说明能否直接登录或需要审批。
4. 提交后，非 MDE 注册会直接登录；MDE 申请则显示待审批结果。

页面会说明新账号加入的评估组织。有种子数据时是 ChargeLab，否则需要恰好一个可用的初始组织。没有组织选择框，个人资料也不能修改归属组织。如果没有可用组织，或存在多个组织而无法确定加入对象，请联系部署运维人员处理。注册不包含邮箱验证，也不等于接受邀请。

## 等待 MDE 申请获批

在「注册」（`/`）申请硬件MDE 或软件MDE 时，系统创建的是**未激活账号**和待审批角色申请。虽然会记录对应的基础开发角色，但未激活账号仍不能登录，审批前也不会获得会话。

请联系组织管理员审核。获批后，回到「登录」（`/`），使用注册时的用户名和密码登录。审批会激活账号，并授予申请的 MDE 角色。

## 审批 MDE 注册申请

具有 `users:manage` 权限的管理员使用「注册申请」队列。审批步骤和组织范围见[组织管理指南中的审批 MDE 注册申请](organization-and-governance.md#审批-mde-注册申请)。提交 MDE 注册申请本身不代表已获授权。

## 没有管理员时寻求帮助

如果「登录雷泽」（`/`）显示「还没有管理员账号」，请联系部署运维人员。页面提供了在服务器创建首位管理员的提示；普通用户不能通过自助注册获取管理员角色。具体运维流程见[身份认证参考](../api/authentication.md)。

## 修改自己的本地密码

1. 在已登录的工作区，例如「我的工作台」（`/parameter-home`），打开顶部用户菜单，选择「个人资料」。这是弹窗，不是独立路由。
2. 在「修改密码」中填写当前密码、与当前密码不同且至少八个字符的新密码，以及确认密码。
3. 提交后，**当前本地会话保持登录，其它会话退出**。在其它窗口或设备重新登录时，使用新密码。

## 重置成员的本地密码

具有 `users:manage` 权限的管理员从「组织管理」（`/organization`）进入「人员管理」（`/organization/members`）。在成员所在行选择「重置密码」，填写至少八个字符的新密码及确认密码，然后选择「确认重置」。

与自行改密不同，**该成员的全部本地会话都会退出**，需要使用新密码重新登录。此操作要求成员已有本地密码凭据，不能用于重置外部身份提供方的密码。

## 在 OIDC 部署中登录

使用部署运维人员提供的身份提供方登录入口，再打开 WiseEff 的 `/`。浏览器身份集成获取并刷新访问令牌；服务端根据 WiseEff 中的记录确定账号是否激活、归属组织和实际权限。仅在身份提供方登录，不会自动获得 WiseEff 角色。

当前 WiseEff 认证页没有专用的 OIDC 登录按钮或路由。如果 OIDC 部署仍显示本地「登录雷泽」（`/`）表单，请联系运维人员检查浏览器身份集成，不要另注册本地账号代替。外部账号的密码按身份提供方流程处理。部署细节见[身份认证参考](../api/authentication.md)。
